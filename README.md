# AVS Sampler releases

This repository contains Developer ID signed and Apple-notarized AVS Sampler builds and the Sparkle automatic-update feed.

Download the latest Apple Silicon release from [Releases](https://github.com/kokafang/avs-sampler-updates/releases/latest).

The app bundles its required media tools. Users do not need Homebrew, Python, JavaScript, yt-dlp or FFmpeg installed separately.
